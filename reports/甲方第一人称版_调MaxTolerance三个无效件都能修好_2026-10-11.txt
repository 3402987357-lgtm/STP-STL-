一、我要验证什么

上一轮我用**默认参数**的 ShapeFix_Shape 做实验，得出：

    训练集/4  无效 -> 有效（可修）
    测试集/2  无效 -> 仍无效（我写成"更深"）
    训练集/1  无效 -> 仍无效（我写成"更深"）

当时我明确写了"只用了默认参数，调了也许另两个也能修好，**未验证**"。
这一轮就去验证，**不把未验证的可能当结论**。

二、先定位：起作用的是 MaxTolerance

我试了 6 组配置（`Precision`、`MinTolerance`、`MaxTolerance`、
`FixVertexPositionMode` 及其组合）：

    测试集/2（修前 False）
      默认 False / 精度1e-4 False / 最小容差1e-4 False
      **最大容差=0.5 True** / 顶点位置+精度 True
    训练集/1（修前 False）
      默认 False / 精度1e-4 False / 最小容差1e-4 False
      **最大容差=0.5 True** / 顶点位置+精度 True
    对照 测试集/1（修前 True）：各组**均 True**（**没被修坏**）

**起作用的开关是 `SetMaxTolerance`**，不是 Precision 也不是 MinTolerance。

（`顶点位置=True` 这组我报错 TypeError，是我赋值方式不对，**未验证**。）

三、再扫一遍找最小可行值（关键：代价到底多小）

0.5 mm 对机械零件是很大的容差，我担心会把形状"糊"掉，所以扫了
0.05~0.5 八档，并**同时量修前修后的面数与表面积**，看几何有没有被改坏：

    测试集/2  修前 False 面141 面积140.1530
      MaxTol=0.05 **True** 面141 面积变化 -0.000%   （0.06~0.5 全部 True）

    训练集/1  修前 False 面730 面积8100.9772
      MaxTol=0.05 False  面730 面积变化 -0.002%
      **MaxTol=0.06 True** 面730 面积变化 +0.000%   （0.08~0.5 全部 True）

    训练集/4  修前 False 面99 面积288.6005
      MaxTol=0.05 **True** 面99 面积变化 -0.000%
      MaxTol=0.06 **False**（0.08/0.1/0.15/0.2/0.3/0.5 **全部 False**）

    对照 测试集/1 修前 True 面67：0.05~0.5 **全部 True**，面积变化 +0.000%

四、结论

1. **我前两轮"测试集/2、训练集/1 更深、ShapeFix 修不了"是错的**——那是
   **默认参数下的结论，不是能力边界**。调 `MaxTolerance` 后：
   - 测试集/2：**0.05 起**即可修好；
   - 训练集/1：**0.06 起**即可修好。
2. **代价很小，不是我担心的 0.5 mm**：最低 0.05~0.06 mm。
3. **没有以损坏几何为代价**：面数**完全不变**，表面积变化在 **±0.002%**
   以内，对照件也**没被修坏**。
4. **`训练集/4` 表现出反常的非单调行为**：0.05 有效，**0.06 及以上反而
   全部无效**。这与我上一轮"它可修"的结论方向一致，但说明那个结论
   **极为脆弱**——只在很窄的容差窗口内成立。

五、我要更正的两句话

- 前两轮我写"ShapeFix 修不了 = 问题更深"。**更正**：修不了是**默认参数**
  的结果；参数一放，**问题并不深**。
- 上一轮我写"训练集/4 可修"。**补充**：可修，但**只在 0.05 附近成立**，
  放大容差反而变差。这个非单调性我上一轮不知道。
