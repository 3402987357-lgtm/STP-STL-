二、训练集/4 到底是什么

前几轮我把力气都花在训练集/1 和测试集/1 上，**训练集/4 一直没单独查**。这轮查了：

    status = NO_ACTION，**环数 = 0**（完全没检测到破损区域）
    输入件本身：Solid 数 = **1**，体积 = **246.239092 mm³**
    缝：11 条、**总长 0.011224 mm**、单条最大 0.004709 mm（都远低于 0.05 容差）

**它本来就是个完好的实体**——没有破损，所以 NO_ACTION（不动它）是**正确行为**。

三、误判在哪

基准原来这样算（benchmark:347-355）：

    after_boundary = after_solids = after_gap = None
    if output_path.exists():        # 只有写出了才量
        ...量 after_*
    closed = after_boundary == 0 or (after_gap <= 容差 and after_solids > 0)

**没写出文件 -> 三个值全是 None -> 两个分支都落空 -> 一律 False。**

而训练集/4 不写出的原因恰恰是"**它不需要修**"。一个本来就封闭的完好件，仅
因为"不需要修所以没写出"就被算作未封闭——**这是误判**。

四、怎么修的

**不写出意味着"原样保留"（不伤害保护），那输出就等于输入**，所以 after_* 该
取输入件的值：

    probe_path = output_path if output_path.exists() else step_path

五、为什么这不是"改分数放水"

1. 判据本身**一个字没改**（还是 `after_boundary == 0 or (gap<=容差 and
   solid>0)`），只是**填上原本缺失的测量值**。
2. **反例验证**：训练集/1 同样未写出，退回量输入件后它的缝总长是
   **0.140364 mm > 0.05 mm**，**仍旧判 False**（实测确认，表里可核对）。
   所以这不是"未写出就放行"。
3. 训练集/4 变成 True，是因为它**真的**满足判据：Solid=1、缝总长 0.011 mm。
