# 任务书示例图（我从原件里补抽出来的）

## 我为什么补这一份

`scripts/import_task_books.py` 当初只抽 `word/document.xml` 的**正文文字**，
注释里也写明了"不复制图片与排版"。后果是任务书里的"示例："和"示例图"
后面跟的图**一直没人看过**——而正文的"示例图"是任务书表格里的一列，
它本身就是甲方对需求的一部分表述，不该在交付物里缺席。

所以我按正文顺序把这 3 张真正被引用的图补了进来。

## 这三张图各自说明了什么

**示例图1（缺失区域与误差测量）**：一个 CAD 件，面上带三角化边线，
一条**红色测量线**连到缺口处，旁边挂着数值标签
`最小距离 ▾ 2.7847 mm`。这是任务书对"计算几何误差、识别缺失区域"
的可视化示意：甲方想看的是**缺陷位置 + 该处的几何误差数值**。

**示例图2（STL）**：蓝色着色网格，示意 STL 是三角面离散网格。

**示例图3（STP）**：灰色着色模型，面上带 B-Rep 面边界线，
还画了坐标轴与一个基准标记，示意 STP 是参数化 CAD 模型。

## 和当前实现的对应关系

示例图1 想要的东西，数据层已经齐了：`regions.csv` 有
`center_xyz_mm`（位置）、`bbox_min_xyz_mm`/`bbox_max_xyz_mm`/`area_mm2`（范围）、
`max_error_mm`/`mean_error_mm`/`p95_error_mm`（对应误差数据），
`result.json` 里同样有。所以任务书"识别结果应包含位置、范围及误差数据"
这条是**满足**的。

**2026-10-17 补：这一处差别已经补上了。** 此前的可视化只把区域高亮出来，
图上没有数字；现在 `_draw_panel` 会在区域中心标 `#序号 数值mm`，
并加半透明白底（数值常压在深色模型上，没底色等于没标）。
两条限制写死在实现里：只标**本行网格空间**里的区域（missing 属于参考件、
extra 属于待检件，否则同一个数字会在"修复前/修复后"两行各出现一次），
以及区域数超过 20 时不标数字（噪声件能出几千个区域，逐个标会把图糊成一片）。
实拍验证见 `测试集/3` 的对比图：`#1 1.002mm`、`#2 0.177mm`。

HTML 明细表仍是"区域/分类/状态/面积/需要复核"五列，本轮没有加误差列；
三项误差（max/mean/p95）本来就在 `regions.csv` 与 `result.json` 里。

## 怎么重新抽一遍

我没有把这个步骤并进 `import_task_books.py`（它刻意只做正文文字，
改它会牵动现有的溯源用例）。要重抽时按正文顺序取那 3 个 `r:embed`
指向的 `word/media/*.png` 即可；判断"哪张被真的引用"的依据就是
该 rId 在 `document.xml` 里出现次数大于 0。
