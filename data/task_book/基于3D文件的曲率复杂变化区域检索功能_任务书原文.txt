001| 题目：
002| 基于 3D 文件的曲率复杂变化区域检索功能
003| 项目任务概述
004| 基于 Python 制作一个应用，读取 3D CAD 文件（.stp/.step），识别曲率复杂变化区域，并返回其 3D 空间坐标及对应的 2D 图纸映射区域坐标。
005| 项目目标
006| 项目内容主要包括以下三点：
007| ）识别 3D 模型中所有符合 2 条几何特征的曲率复杂变化区域；
008| ）返回每个符合特征区域的 3D 空间坐标区域；
009| ）将 3D 特征区域映射到 2D 图纸，返回对应的 2D 区域坐标，支持多面特征全部输出。
010| 曲率复杂变化区域几何特征描述
011| 特征规则如下：
012| 序号
013| 几何特征规则
014| 说明
015| ①
016| 存在曲面特征
017| 该区域必须包含曲面几何特征（如 NURBS 曲面、B-Rep 曲面等）
018| ②
019| 存在复制曲率变化面
020| 该区域存在曲率变化模式的复制/阵列特征（如周期性曲率变化、镜像曲率分布等）
021| 项目需求
022| 模块功能、性能要求
023| 具体功能与性能要求如下：
024| 核心功能要求
025| 3D CAD 文件解析能力（前置要求）
026| 系统应能原生读取并准确解析主流 3D CAD 文件格式，包括 .stp/.step（AP203、AP214、AP242）、.igs/.iges 等，完整提取实体、曲面、边界表示（B-Rep）、拓扑结构等元素信息进行处理，确保数据无丢失、无错位。
027| 曲率复杂变化区域提取（核心任务一）
028| 1）自动提取 3D 模型中所有曲面特征区域。
029| 2）计算每个曲面的曲率属性（高斯曲率、平均曲率、主曲率等）。
030| 3）识别曲率变化模式，检测是否存在复制/阵列的曲率变化特征。
031| 4）支持不同尺寸、不同方向、不同曲率类型的复杂变化区域识别。
032| 几何特征规则检测（核心任务二）
033| ）对每个提取的曲面区域，依次应用 2 条几何特征规则进行判定。
034| 2）曲面特征检测：验证区域是否包含曲面几何元素。
035| ）复制曲率变化检测：分析曲率分布模式，识别是否存在周期性、镜像、阵列等复制曲率变化特征。
036| ）输出每个区域的规则符合情况（2 条规则的通过/失败状态）。
037| 3D 空间坐标区域输出（核心任务三）
038| ）对于每个符合全部 2 条规则的曲率复杂变化区域，准确计算其 3D 空间包围盒（Bounding Box）。
039| ）精确输出该包围盒的最小角点（MinX, MinY, MinZ）和最大角点（MaxX, MaxY, MaxZ）的世界坐标。
040| ）为每个符合条件的区域生成唯一标识 ID（如：CCR_001、CCR_002...）。
041| 2D 图纸映射坐标输出（核心任务四）
042| ）将 3D 特征区域投影映射到指定的 2D 图纸平面（如 XY、YZ、XZ 平面或用户定义的投影方向）。
043| ）计算映射后的 2D 区域边界坐标（多段线或封闭轮廓）。
044| ）输出 2D 区域的最小外接矩形坐标（MinX, MinY）和（MaxX, MaxY）。
045| ）支持多视角映射输出（如前视图、顶视图、侧视图等）。
046| 多面特征批量处理（核心任务五）
047| ）当存在多个面符合特征时，全部返回①②中的要求（3D 坐标区域 + 2D 映射坐标）。
048| ）以结构化数据（如 JSON）的形式存储检测结果，包含：区域 ID、3D 包围盒坐标、2D 映射坐标、规则判定详情、曲面属性（曲率值、面积、法向量等）。
049| ）生成可视化报告，标注所有符合条件的特征区域位置。
050| 性能与可靠性要求
051| ）检测精度：在甲方提供的标准测试集（≥200 个包含不同曲面类型、曲率复杂度和复制模式的 3D CAD 样本）上，综合直通率（正确识别并定位）≥ 96%，误报率 ≤ 4%。
052| ）处理效率：单文件（≤500+ 曲面实体）全流程检测耗时 ≤ 5 秒（测试环境：Intel Core i7 / 16GB RAM / SSD）。
053| ）兼容性：支持 Windows 10/11 操作系统；兼容主流显卡驱动。
054| ）稳定性：连续运行 72 小时无内存泄漏或崩溃；对损坏的 3D 文件应弹出友好提示而非程序异常退出。
055| 5）安全性：所有模型数据仅在本地处理，不得联网传输；操作日志记录检测时间、文件名、区域统计，保留 ≥180 天。
